# LinkedIn Case Study

## Project title

AI News Research Assistant — Two-Stage RAG Pipeline with OpenAI and Pinecone

## Featured section description

Built a production-style Retrieval-Augmented Generation project that uses OpenAI embeddings and Pinecone vector search to answer natural language questions from a news article dataset.

The system indexes article titles as vector embeddings, retrieves semantically relevant articles, builds grounded context from article metadata, and generates an LLM response using only the retrieved context.

Key skills demonstrated:

- RAG pipeline design
- OpenAI embeddings
- Pinecone vector database
- Semantic search
- Metadata-aware context construction
- Prompt grounding
- Python engineering
- GenAI QA testing strategy

## Resume bullet

Designed and implemented a production-style RAG prototype using Python, OpenAI, and Pinecone, enabling semantic retrieval over news articles and grounded LLM answer generation; added batching, metadata validation, token safety handling, and a QA test strategy covering retrieval relevance, hallucination risk, prompt injection, and API failure scenarios.
